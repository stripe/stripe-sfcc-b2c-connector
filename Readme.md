# Stripe Salesforce Commerce Cloud Cartridge

This repository contains the Stripe integrations with the Salesforce Commerce Cloud platform. There are two versions currently available for SiteGenesis Javascript Controller (SGJS) and Salesforce Reference Architecture (SFRA) which have the Alternative payment methods (Express Checkout, Payment Element and Checkout Sessions with adaptive pricing)

## Visit our [Documentation](https://docs.stripe.com/use-stripe-apps/salesforce-commerce-cloud) to start using the Stripe Salesforce B2C Connector.
